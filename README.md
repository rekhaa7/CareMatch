# CareMatch: Elderly–Volunteer Matching System

## Overview
CareMatch is a data-driven system designed to match elderly individuals with suitable volunteers based on their needs, location, and availability. The goal is to improve accessibility to support services for older adults while efficiently utilizing volunteer resources.

---

## Problem
Many elderly individuals require assistance with daily activities (ADLs/IADLs) but lack access to immediate support. At the same time, volunteers are available but not optimally matched.

This project solves the **matching gap** using data-driven logic.

---

## Dataset
- Simulated dataset inspired by real-world elderly care scenarios
- Features include:
  - Age
  - Mobility needs
  - ADL/IADL assistance requirements
  - Location
  - Volunteer skills & availability

---

## Approach
- Data cleaning and preprocessing
- Feature engineering for:
  - Assistance level
  - Skill compatibility
- Matching logic based on:
  - Geographic proximity
  - Skill–need alignment
- Clustering to group similar profiles
- Matching score calculation

---

## Results
- Efficient pairing between elderly individuals and volunteers
- Improved match relevance based on needs and skills
- Demonstrated scalable matching logic for real-world application
